# 拾声集 · XianDial Suite

**一台 ESP32-S3 竖屏桌面机，一个固件里装着四样东西：网络电台、观音灵签、天气时钟、股票行情。**

> 🌐 **English: [README.en.md](README.en.md)** · 烧录 / Flashing: [FLASHING.md](FLASHING.md) · [FLASHING.en.md](FLASHING.en.md)
>
> 名字取「拾取声音」＋「集」—— 四样功能汇成一集，摆在案头，其中一样就是时间。
> 底座与开源项目 **拾声 XianDial** 同源：同一套显示、触摸、字库、音频、电源，
> 四个产品只换界面层与数据层，**不必各自一台机器**。

## 四个产品

首页是 2×2 宫格，点卡片进入；每个产品返回后即销毁自己的界面（反复进出不累积内存）。

| # | 产品 | 做什么 |
|---|---|---|
| 0 | **拾声电台** | 网络电台直播（按 13 栏目 / 42 地区分类筛选）+ SD 卡本地音频播放，带实时频谱 |
| 1 | **观音灵签** | 传统观音灵签 100 签：默念《心经》→ 选所求之事 → 摇签 → 揭晓签诗（竖排）→ 五层解签；签诗可朗读 |
| 2 | **天气时钟** | 实时天气 + **72 px 大时钟**、日期、湿度 / 空气 / PM2.5、未来三天预报；可语音播报 |
| 3 | **股票行情** | 自选股实时涨跌（**涨红跌绿**，国内规矩）+ 当日分时 + 日 K 线（含 MA5/10/20） |

**灵签的吉凶与宫位分布按古本** —— 上签 22 / 中签 60 / 下签 18，十二宫不等长分布，
不是网上常见的仿作改编版。

## ★★ 先说清楚：两种形态（台单）

本仓库按**发布版**形态发布。台单（电台清单）是两种形态唯一的区别：

| | **发布版**（本仓库默认，`main/net_stations_pub.c` 存在时） | **自用版** |
|---|---|---|
| 内置台单 | **0 条** | **1254 条**（实机计数） |
| 台名字库 | `fonts/xs_font_pub_st16.c`（GB2312 一级 3755 字 / 2 bpp） | `fonts/xs_font_st16.c`（按本机台单用字烘 776 字 / 4 bpp） |
| 收藏播种 | 不播种（`XS_FAV_PUBLISH=1`） | 播种本机常听 10 台 |
| 固件大小 | 5,588,592 B | 4,734,400 B |

**为什么发布版要清干净**：台单不是我写的内容，而是一份**索引**。
把它随固件一起分发，等于替别人广播；而且那份清单里有些地址是本机实测才拿到的。
⇒ 发布版台单置空，**你自己的电台由你推给自己的机器**（下一节）。

> ★ 判别手上这版固件是哪种形态，**只有一条路**：去 `build/lingqian-radio.bin` 里数台名。
> 两个台单文件同时在时，CMake 会**静默**走发布分支 —— 源码扫描查不出这件事。

## 加自己的电台：三步

### ① 准备一份 TSV

四列，**TAB** 分隔，UTF-8 无 BOM、LF 换行：

```
台名	栏目	地区	URL
上海戏曲广播	戏曲	上海	http://lhttp.qtfm.cn/live/5054/64k.mp3
中国之声	新闻综合	全国	http://satellitepull.cnr.cn/live/wxzgzs/playlist.m3u8
```

- **栏目**必须落在 13 个标准名里：
  `新闻综合 交通台 音乐 文艺 说书 戏曲 怀旧老歌 网络台 教育台 电视伴音 综合 宗教 境外新闻`
- **地区**必须落在 42 个标准名里（31 个国内省级 + 中国台湾 / 中国香港 / 中国澳门 + 其他华语 / 北美 / 欧洲 / 日韩 / 新马 / 东南亚 / 大洋洲 / 海外中文），
  或填 `全国`（表示无地区归属）
- **URL** 支持明文 HTTP 直连、HTTPS 直连，以及 **HLS**（`.m3u8`）

### ② 推进机器的 SD 卡（`/sdcard/stations.tsv`）

- 用 `tools/_sd_push.py`（串口逐行推，自带回读校验与 `st_reload`），或
- 直接把卡拔下来用读卡器拷进去

机器上有串口命令可就地验证：

```
st_ls          # 看卡上有没有 stations.tsv、多大
st_reload      # 重新读一遍台单（不用重启）
```

### ③ 让台名不显示成方块

台名字库是按「实际用字」烘的。你自己那份台单里若有生僻字 / 繁体字，需要重烘一次：

```bash
python gen_fonts_st.py --proj=lingqian-radio --only=16 --ui-font=<楷体 ttf>
# 然后删掉 main/net_stations_pub.c，让 CMake 走自用分支
```

> 台名字库为什么分两档、为什么不能直接用全字集：见下面「字体」一节。

## 硬件规格

作者自用机的实测配置。**这份固件只在这套硬件上验证过** —— 换屏、换触摸控制器、
换音频通路都需要改代码。

| 项 | 规格 |
|---|---|
| 主控 | **ESP32-S3**（512 KB SRAM / **8 MB PSRAM** / 16 MB flash） |
| 屏幕 | **3.5 英寸 IPS TFT**，**320×480 竖屏**，ST77922 驱动，QSPI |
| 触摸 | FT6336G 电容触摸（I²C） |
| 音频 | ES8311 codec → FM8002E 功放，单声道喇叭（`PA_EN` = IO1，低电平使能） |
| 存储 | 板载 **TF 卡座**（SDIO 四线） |
| 电源 | 3.7 V 锂电池 + LDO；支持 deep sleep 关机（BOOT 键唤醒） |
| 框架 | ESP-IDF 6.1 + LVGL 9 |
| 分区 | app 分区 7 MB，**无 OTA**，升级需重新烧录 |

**竖屏是原生姿态，不是旋转出来的**：面板本身就是 320×480，显示 flush 零旋转，
触摸坐标 `raw == lv`。装修朝向不对时只改 `main/app_pins.h` 里一个宏：

```c
#define LQ_PORTRAIT_FLIP 0      /* 只改这一个；别分别翻转显示和触摸 */
```

> ★ **不要分别翻转显示和触摸** —— 那会出现「点屏幕全落到对面」，四角怎么试都不全对。

## 隐私（这一节是承诺，不是宣传语）

### 这台设备在网络上做什么

四个产品里只有两个联网，出站地址是**固定的、写死在代码里、可在本仓库核对的**：

| 用途 | 地址 | 说明 |
|---|---|---|
| 天气 | `t.weather.itboy.net` | 实时天气，**只 GET** |
| 股票报价 | `qt.gtimg.cn` | 自选股实时行情，**只 GET** |
| 股票 K 线 | `money.finance.sina.com.cn` | 分时与日 K，**只 GET** |
| 时间校准 | `ntp.aliyun.com` | SNTP 校时 |

**除此之外，唯一会连出去的就是你自己填的电台地址**（发布版内置台单为 0 条）。

### 你可以自己验证

```bash
# 固件里所有固定出站域名
grep -rhoE "http://[A-Za-z0-9._-]+" main/*.c main/*.h | sort -u

# 确认没有 POST / PUT 出站（只应有 GET）
grep -rn "HTTP_METHOD_POST\|HTTP_METHOD_PUT" main/
```

### 设备本地存了什么

- **NVS**（`xs_cfg` 命名空间）：音量、背光、静音，以及配网用的 WiFi 凭据
- **SD 卡**：你推的台单与音频
- 没有账号、没有遥测、不上传任何使用数据

## 编译与烧录

详见 **[FLASHING.md](FLASHING.md)**。要点：

- 需要 **ESP-IDF 6.1**
- 刷**合并镜像**最省事；或按分区表分别刷三件套

| 文件 | 烧到 |
|---|---|
| `bootloader.bin` | `0x0` |
| `partition-table.bin` | `0x8000` |
| `lingqian-radio.bin` | `0x10000` |

> ⚠️ **不要把 `lingqian-radio.bin` 单独刷到 `0x0`** —— 那是把应用程序写进引导程序区，板子起不来。

## 字体

界面用 **霞鹜文楷 LXGW WenKai**（SIL OFL 1.1，允许嵌入固件、允许子集化）。

**四档常规字号 + 一档专用**：

| 档 | 用在哪 |
|---|---|
| 14 px | 说明小字 |
| 18 px | 卡片标题、预报行、按钮 |
| 22 px | 天气词、解签正文、城市名、日期 |
| 30 px | 首页题字、签诗、大温度 |
| **72 px** | **只给时钟**（`xs_font_clk72`，只含 `0-9 : -` 共 12 个字形 / 55.5 KB） |

> ★ **为什么时钟要单独一档**：主字库 2081 字，整体抬到 72 px 需要约 16.6 MB，
> 而 app 分区只有 7 MB。时钟内容恒定是 `%02d:%02d`，只烘那 12 个字形 —— **相差 500 倍**。
> 这是「字库按用途分档」的正常做法：大字号只服务固定短语时，就该只烘那几个字。

**台名字库**另有两档（见上面「两种形态」表）：发布版用 GB2312 一级全集
（通用、能开箱即编），自用版按本机台单用字烘（更小、更贴合）。

## 已知限制

- **无 OTA**：升级要重新烧录（分区表里没留 OTA 槽）
- 网络电台走**明文 HTTP 或 HTTPS 直连 / HLS**；但内部 RAM 最大连续块只有约 31 KB，
  而 TLS 握手需要 16~40 KB **连续**内存 ⇒ **依赖 TLS 的台播不出来**
  （这是硬件内存的硬限制，不是 bug）
- 台名里的**生僻字 / 繁体字**需要重烘字库才显示（否则是豆腐块）
- 天气与行情来自第三方公开接口，**不保证可用性与准确性**
